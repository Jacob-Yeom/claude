# Memory

Jacob(염종학)에 대한 작업 컨텍스트를 사실 단위로 정리한 메모리입니다.
모든 내용의 출처는 저장소 루트의 `CLAUDE.md`이며, 그 파일이 원본입니다.

## 구조

| 파일 | 내용 |
|---|---|
| `profile.md` | 이름, 소속, 역할 등 기본 신원 |
| `topics/communication.md` | 응답 언어, 소통 방식, 작업 진행 방식 |
| `areas/argos.md` | 주 개발 대상인 ARGOS 플랫폼의 목적, 기술 스택, 개발 규칙, 설계 원칙, 기능 영역 |
| `topics/document-toolchain.md` | PPTX·DOCX·HWP 등 문서 생성 도구와 형식 규칙 |

## 작성 규칙

- 한 줄에 하나의 사실만 적습니다.
- 사용자가 직접 밝힌 내용만 담습니다. 추정이나 해석은 넣지 않습니다.
- 내용이 바뀌면 `CLAUDE.md`를 먼저 고치고, 이 폴더를 그에 맞춰 갱신합니다.
