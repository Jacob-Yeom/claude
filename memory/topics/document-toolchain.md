# Document Toolchain

## 도구 선택
- PPTX 신규 생성: `pptxgenjs`
- PPTX 기존 파일 수정: `python-pptx`
- DOCX: Node.js `docx` 라이브러리
- 이미지 처리: `sharp`
- 아이콘: `react-icons`
- 납품 전 점검: PDF로 렌더링한 뒤 `pdftoppm`으로 이미지를 떠서 레이아웃과 오버플로를 시각 점검한다.

## 공통 규칙
- 출력 파일명은 ASCII만 사용한다. 한글 파일명은 다운로드와 압축 해제 오류를 일으킨다.
- 변경 표시 규칙은 Excel·HTML·PPTX에 공통 적용한다: 신규는 청색, 일부 수정은 적색, 변경 없음은 흑색.
- 기본 디자인은 다크 네이비 테마다.
- 참조 템플릿이 주어지면 그 구조와 스타일에 충실히 맞춘다.
- 이전 산출물을 이어서 수정하는 방식이 기본이다.

## 정부 제출 문서 형식
- 개조식(□ / ㅇ / -)으로 쓴다.
- 목차는 Ⅰ/Ⅱ/Ⅲ 위계를 따른다.
- 글꼴은 맑은 고딕이다.
- 최종본은 HWP(12pt, 100쪽 이내)다.
