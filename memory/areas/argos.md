# ARGOS — 전출처 정보융합분석 플랫폼 (국방)

## 목적과 현황
- 북한 및 주변국 대상 정보융합 분석 플랫폼이다.
- 국방용 "ARGOS Enterprise"를 V26 데모에서 Clean-Build로 재구현하는 중이다.
- 기준 문서는 요구사항 스펙 v1.0 3종(Master Requirements / UIUX Screen Spec / Function Traceability Matrix)과 Developer Master Prompt다.
- 대메뉴 7개는 고정이다: 통합상황 · 정보운영 · 수집임무 · 분석/융합 · 표적/결심 · 보고서/협업 · 체계운영.
- 11월 서밋에서 노트북 10대로 동시 체험을 운영한다.

## 기술 스택
- DB: PostgreSQL 18 + PostGIS
- ORM: Prisma. `db push` 전용이며 migrate는 사용 금지
- 백엔드: Fastify
- 프런트엔드: React + TypeScript + Vite
- LLM: 로컬 Ollama
- 보고서 생성 모델: `qwen3.6:35b`
- 기본 모델: `qwen3.5:9b`

## 개발 규칙 (반드시 준수)
- 유료 서비스·유료 API 사용 금지
- 펄스K 연동은 사용자가 지정할 때만 한다
- 명령 실행과 확인은 PowerShell 기준으로 안내한다. bash 문법 금지
- 폐쇄망 제약은 지금 단계에서 고려하지 않는다. 먼저 제기하지 않는다
- 멀티유저 동시 접속을 전제로 설계한다

## 설계 원칙
- HITL 원칙: AI는 초안만 생성하고, 최종 판단은 분석관이 확정한다.
- 판정의 단일 진실원천은 백엔드다. ACH 판정엔진과 융합엔진 규칙이 판정을 맡는다.
- Sage AI(대화형 보조)는 설명과 DB 조회만 한다. 판정은 하지 않는다.
- 북한의 무기 관련 활동은 자동으로 위협 사건에 포함한다.
- 주체가 확인되지 않은 사고는 도발로 단정하지 않는다.
- LOCUS(지도부 동선) 판정은 정직성이 최우선이다. 근거가 부족하면 부족하다고 표시한다.
- UI 기준은 Calm · Evidence-first다. 빨간색(Red)은 절제해서 쓴다.

## 기능 영역

### 보고 엔진
- 수시·일일·주간·월간 보고를 만든다.
- 일일보고의 집계 구간은 전일 06:00부터 당일 06:00까지다.
- 문체는 정보기관 문체로 한다.
- 전망 문장에는 근거·목적·시한을 담는다.
- 대상국은 미·중·일·러 4국이다.
- 군사력 DB는 대상국 4국에 인도·호주를 더한 6국 기준이다.
- 월간보고는 브리핑 모드와 편집 가능한 PPTX로 출력한다.
- 승인된 보고서를 예시 도서관으로 모아 활용한다.

### 그 외 영역
- 언론보도 평가서는 독립 화면으로 두며, 원문 인용을 원칙으로 한다.
- 소셜·OSINT 탐색에서도 AI가 판정을 확정하지 않는다.
- 군사 기초상식 DB에는 국방백서 2010~2022판을 이식했다. 2026판도 발간되면 이식한다.
- GEOMAP은 외부 시연 전에 Esri 위성영상 이용 조건을 확인해야 한다. (미결)
